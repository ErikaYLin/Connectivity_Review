# Habitat connectivity literature review

Author and Maintainer: Erika Y. Lin

*Last updated: 2026-11-21*

Supporting materials, data, and code for a literature review on habitat connectivity: "Translating connectivity to conservation action: A global review of recent studies and methods in habitat connectivity"

----

## File directory

| File | Description |
|:---|:---|
| `connectivity_data_cleaning.R` | Detailed working code for initial data cleaning. |
| `connectivity_analysis.R` | Detailed working code for analyses and figures. |
| data | Directory containing various data sets used in the data cleaning and analysis process. All articles were obtained from the Web of Science (WOS) Core Collection. |
| `data/filtered_abstracts_annotated.csv` | Data set: Annotated data curation including the top 12,031 articles, sorted by relevance to the search query and filters. The top 65 articles were reviewed, with a final sample of 50. Note that this was converted into a CSV file for the analysis. As such, it may contain minor errors which were fixed throughout the analysis. |
| `data/woscc_adjusted-query_all.csv` | Full exported results based on the initial search query prior to additional filtering. Results matched the search terms, but also included any articles with limited relevance to the aims of this review. |
| `data/woscc_adjusted-query_filter_all.csv` | Exported results based on the search query with filtering for publication year range and WOS categories (see above). This data set was converted into a CSV file and used for initial data cleaning, as shown in the Appendix. |
| Supplementary_Materials | Directory containing final supplementary materials included for publication. [TO BE UPDATED] |
